Run the toolkit on the store

The workshop examples are small on purpose. The AI for Accessibility Toolkit has about 50 adapters, and most of them run on Redbird as they are. Each link on this page opens the store with an issue turned on and the toolkit's fix for it running.

Run the automatic fixes

In the browser extension, the toolkit first checks the page with axe-core, then fixes each problem it finds. Some of these fixes use AI. For example, it looks at product photos to write alt text, and names buttons that have no name.

  1. Open the Redbird Basics charger with the automatic fixes running (opens in a new tab). This turns on issues 1, 2, 9, 10 and 12.
  2. Wait a few seconds while it describes the photos.
  3. Turn on a screen reader, or right-click a product photo and click Inspect. Photos that had no alt text now have a description, and the icon buttons have names.

Photos whose alt text is a file name, like "DSC00418.webp", are left as they are. The toolkit doesn't fix those yet. To build that fix, see Pick an issue to fix.

Note

These fixes change the page in place. Deselecting toolkit-fixes in the panel reloads the page without them.

Run several at once

To run more than one adapter, separate their names with commas in try=. For example, this runs motion-reducer, unpin-sticky and big-targets on the home page (opens in a new tab).

Tip

Any adapter file name in the toolkit's tools/adapters folder (opens in a new tab) works with try=.
