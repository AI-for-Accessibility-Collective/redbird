Turn business days into dates

Redbird says "5–7 business days" instead of a date, so you have to count the days yourself. In this guide, you run the real-arrival-dates adapter, which counts them for you, and then change how it writes the dates.

See the issue

  1. Open the search results for "charger" (opens in a new tab) with only issue 31 turned on.
  2. Look at the shipping line under each price. It says something like "FREE Standard Shipping (5–7 business days, excluding weekends and holidays, subject to carrier availability)". To know the date, you have to count five weekdays from today.

Turn on the adapter

  1. Open the search results with the adapter running (opens in a new tab). This also loads Sam's profile, which has "concreteDates": true.
  2. Look at the shipping lines again. They now show dates, for example "arrives Tue, Oct 27 – Thu, Oct 29" (yours depend on today's date). To see what the store said before, hover over one.
  3. To compare the page with and without the adapter, deselect real-arrival-dates in the Workshop panel on the left, then select it again. The Changes tab lists each line it rewrote, with what the store said before. Click one to see it on the page.

Note

The adapter also works on product pages (opens in a new tab) and at checkout.

Look at the code

The adapter is about 100 lines. This part counts the days. It goes forward one day at a time and skips Sundays (0) and Saturdays (6).

JavaScript
dateAfter(days) {
  const d = new Date(this.today);
  while (days > 0) {
    d.setDate(d.getDate() + 1);
    if (d.getDay() !== 0 && d.getDay() !== 6) days--;
  }
  return d.toLocaleDateString('en-US', { weekday: 'short', month: 'short', day: 'numeric' });
},

The rest of the file finds the shipping text on the page and swaps in the dates, and disable() puts the store's text back. To read all of it, see real-arrival-dates.js (opens in a new tab).

Change one line

  1. Open the store with a copy of the adapter in the code box (opens in a new tab). The code box is in the panel in the bottom-left corner.
  2. In the code box, find the toLocaleDateString line, and change both 'short' values to 'long':
    JavaScript
      return d.toLocaleDateString('en-US', { weekday: 'long', month: 'long', day: 'numeric' });
  3. Click Save and run. The dates now look like "arrives Tuesday, October 27 – Thursday, October 29".

Note

Your copy is saved in this browser. To go back to the blank template, click Start over.

Skip holidays (optional)

The adapter skips weekends but not holidays. Try making it skip Thanksgiving (Thursday, November 26, 2026) too.

  1. In the code box, change dateAfter() so it doesn't count November 26.
  2. To test it, add &today=2026-11-20 to the end of the address and press Enter. The store now thinks it's Friday, November 20, so 5 business days later should be Monday, November 30 (not Friday, November 27).
  3. To go back to the real date, add &today=now to the address.
