Redbird workshop

Fix a fake online store for people with disabilities, using the AI for Accessibility Toolkit.

Why this matters

About 1.3 billion people, or 16% of the world, have a significant disability (WHO, Disability and health (opens in a new tab)). Most of the web still doesn't work well for them. In 2026, WebAIM's checker found accessibility failures on 95.9% of the top million home pages, with about 56 failures per page. The most common were low-contrast text, images with no alt text, and form fields with no labels (The WebAIM Million (opens in a new tab)).

Usually these only get fixed if the site's owner fixes them. The AI for Accessibility Toolkit (opens in a new tab) fixes them in the browser instead, for the person reading the page.

Meet Sam

Sam Saltman is blind and shops with VoiceOver. Sam needs a USB-C charger by Thursday, for under $25. On Redbird, the color choices have no names, the delivery date is hidden behind "5–7 business days", every product title is stuffed with keywords, and a protection plan is already ticked at checkout. Most of this workshop follows Sam's shopping task.

Redbird has 36 issues like these, built in on purpose. You can turn each one on or off, so you can see exactly what an adapter changes.

Why AI, and why agents

  • Some fixes need judgment. A checker can tell that a product photo has no alt text, but writing "white USB-C charger with a folding plug" takes a model that can look at the photo. The same goes for naming a button that has no name, or rewriting a legal paragraph in plain words.
  • People need different things. Sam needs color names and real dates, Mark Sugarberg (ADHD and anxiety) wants countdown timers gone, and Dario Almondei (dyslexia) wants short, plain text at about a 6th grade level. The toolkit reads a profile like this and changes the page for that person.
  • AI agents are starting to shop for people. That can help a lot, but the agent works fast and out of view, and a screen reader user has no quick way to check what it clicked, skipped or added to the cart. Redbird's agent task (opens in a new tab) has six points where an agent should stop and ask the user (e.g., the protection plan that is already ticked). The verification layer lets the user check what the agent did at each of these points.

Get started

Each guide takes about 10 minutes, and you only need a browser. Do them in order:

  1. Turn business days into dates
  2. Name the color choices
  3. Hide pressure messages
  4. Rewrite hard text
  5. Write your own adapter

Store links in these guides open the Workshop panel on the left side of the store. From it you can switch on any profile or adapter, see every change an adapter made (before and after), and run the toolkit's checks on the page.

Tip

If the store gets into a weird state, reset the store (opens in a new tab). This turns all the issues back on, stops the adapters and empties the cart. To change one setting at a time, use Store controls.
