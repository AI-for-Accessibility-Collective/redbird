Redbird workshop

In this workshop, you build an accessibility fix for a person on Redbird, a practice online store, using the AI for Accessibility Toolkit.

  1. Try the toolkit as one of four shoppers, and as yourself.
  2. Learn the framework: ability profiles, adaptations and verification.
  3. Build a fix, following two examples.
  4. Build your own for the person your group picked.
  5. Test it and share it.

Steps 1 and 2 happen during the morning's toolkit intro and framework sessions, and steps 3 to 5 during the afternoon's building sessions.

Note

The toolkit is an active research project: pre-alpha, a technology probe. Its adapters are unvalidated, and it is not a replacement for assistive technology. In practice, a fix can change a page in ways nobody has checked with the people it is meant for, so check it with them before anyone relies on it.

Set up the toolkit

Each team has an account on the toolkit. The organizers give you its name and password. Do this once, in Chrome on a computer:

  1. Sign in to the developer console (opens in a new tab) with your team's account.
  2. Download the toolkit (opens in a new tab) and unzip it.
  3. In Chrome, type chrome://extensions in the address bar, turn on Developer mode, press Load unpacked and choose the extension folder inside the unzipped toolkit.
  4. On the extension's Details, turn on Allow User Scripts. Fixes run as user scripts, and Chrome asks you to allow them.
  5. Go back to the developer console, click the extension's button next to the address bar (pin it from the puzzle piece first) and choose Connect with this console. The extension's sidebar opens beside the page.
  6. In the console, open Apps, press + Connect an app, and under Open the Redbird demo, connected, change the address to https://redbird-workshop.vercel.app and press Open Redbird. The store opens connected to your account, and shows under Apps as Redbird demo.

If a step is hard with the tools you use, ask one of the organizers.

The store's panel

Each store link in this guide opens Redbird with its panel next to it. The panel has four tabs:

  • Profiles is where you pick who to shop as: your own toolkit profile, or one of four made-up shoppers. It shows which adaptations are on for them.
  • Adapter Library has a switch for each of Redbird's own adaptations and each of the toolkit's built-in adapters.
  • Build says how to build a fix with the toolkit.
  • Audit finds common accessibility problems on the page.

You build fixes in the extension's sidebar, not in the store's panel. The sidebar has three tabs: Profile (your profile and your adapters), Builder (an assistant that builds a fix with you) and Settings.

Redbird's built-in problems

We built 36 accessibility problems into Redbird on purpose, the same kinds that real shopping sites have. For example, the color choices have no names a screen reader can say, delivery says "5–7 business days" instead of a date, and countdowns start over every time you visit.

Tip

If the store gets into a weird state, you can reset it. Your fixes are kept in your toolkit account.

Use it on real websites

The fixes you build run in your own Chrome through the extension, so they work on real websites too, like Wikipedia or a shop you use. When you build one in the extension's Builder, the assistant asks which pages it should run on. Please stay signed out of the sites you try, and don't share pages with personal information on them.
