Redbird workshop/Steps/3. Build a fix

Build a fix

Say what gets in the way, and the toolkit's assistant builds a fix with you. Try these two examples first. Each takes about 10 minutes.

How the Builder works

The extension's Builder tab is an assistant beside the page. You say what gets in the way and for whom. It asks a few questions, like who the change helps most and which pages it should run on, and asks to see the page. Then it writes an adapter and previews it on the page: the change shows up right away, but only in this tab, until you add it to your account.

Each preview runs checks, and the assistant tries again by itself when one fails. When it has a version that passes, it offers it to you. A review then runs in the background while you keep trying it and asking for changes.

Note

When the assistant asks to see the page, you choose what to share: the address only, the address and the page source (what is on the page, like headings, buttons and text), also a screenshot, or nothing. With the page source, a copy of the page is kept to check the fix on later. What you share is kept on the toolkit's server for the research and is not used to identify you. Redbird is a practice store, so it has nothing personal on it.

Example 1 below uses one of the toolkit's built-in adapters, and example 2 builds a new one.

Example 1: a calmer page for Mark

  1. Open the Pebble charger page (opens in a new tab). Notice the countdown, "Only 2 left in stock" and the scrolling deals bar.
  2. Open the extension's sidebar and go to Builder.
  3. Type: "I'm building for Mark. He has ADHD and anxiety. Countdowns and messages like only 2 left make him rush, and things moving on the page distract him." Press Send.
  4. Answer the assistant's questions. When it asks to see the page, share the page source.
  5. The assistant may say the toolkit already has adapters for some of this, like calm-page, and suggest adding those, or build a new adapter for what they don't cover. When a preview is on the page, the deals bar stops and the countdown is labeled or gone.
  6. Turn Apply previews off to see the page as it was, then on again.
  7. If something is missing, say it in the box (Additional requests?), like "The countdown at checkout is still there". The assistant changes the adapter and previews the new version.
  8. When it works, press Add to my account. It now runs on the pages it was made for, every time you open them.

Tip

Redbird has its own adaptation for this too: calm-urgency in the store panel's Adapter Library. Compare what the assistant built with it. Turn one off before you try the other, so you can tell which one made a change.

Example 2: star ratings for Sam

Each rating is a picture of stars, so a screen reader only reads the number of ratings, like "(1,203)". None of the toolkit's adapters fix this, so the assistant writes one.

  1. Open the search results for "charger" (opens in a new tab).
  2. In the extension's Builder, press New chat, and type: "I'm building for Sam, who is blind and shops with VoiceOver. Read the star ratings out as numbers, like 4.6 out of 5 stars."
  3. Answer its questions. When it asks which pages to run on, pick this website.
  4. When the preview is on, the stars look the same, since the change is only for the screen reader. Turn on VoiceOver (Command-F5 on a Mac) and move to a rating, or open the preview's line in the chat to see its checks.
  5. In the store's panel, turn on Show accessibility problems on the page. Badge 4 (the star ratings) turns green.
  6. Ask for one more change, like "Also say how many ratings there are". The assistant previews the new version.
  7. Press Add to my account.

Note

The assistant leaves code out of the chat. To see the code, press Export to save the file, or open the adapter on the console's Adapters page.
