Name the color choices

On Redbird's product pages, the colors are just colored circles with no names, and you can't reach them with the keyboard. In this guide, you run the swatch-names adapter, which names each circle and makes the arrow keys work, and then add a color name to it.

See the issue

  1. Open the kettle's product page (opens in a new tab) with only issue 6 turned on.
  2. Click the product title, then press Tab a few times. The focus skips the three color circles. A screen reader has nothing to read for them either, so a blind shopper can't tell which color is which.

Turn on the adapter

  1. Open the kettle with the adapter running (opens in a new tab).
  2. Press Tab until you get to the colors, then press the Left and Right arrow keys. The circles now work like radio buttons, and each one has a name, for example "sage green". Nothing changes on screen.
  3. To hear the names, turn on VoiceOver (Command+F5 on a Mac) or Narrator (Ctrl+Windows+Enter on Windows).

Tip

Without a screen reader, right-click a circle and click Inspect. The circle now has aria-label="sage green" and role="radio".

Look at the code

The adapter starts with a list of color names and a typical shade for each. For each circle, it reads the color and picks the closest name from this list. Then it adds role="radio", aria-label and aria-checked.

JavaScript
const COLORS = [
  ['black', '#161616'], ['black', '#2c2c2c'], ['charcoal gray', '#3d3f42'], ...
  ['sage green', '#9caf94'], ['forest green', '#2f4f3a'], ...
];

To read the whole file, see swatch-names.js (opens in a new tab).

Add a color name

The first circle on the kettle is matte black (#2b2b2b). The closest color in the list is 'black', so that's its name right now.

  1. Open the kettle with a copy of the adapter in the code box (opens in a new tab).
  2. In the code box, add this line right under const COLORS = [:
    JavaScript
      ['matte black', '#2b2b2b'],
  3. Click Save and run.
  4. Press Tab to get to the colors again, or inspect the first circle. It's now called "matte black".

Use the store's own names (optional)

The adapter guesses each name from the color. The store has its own names, and shows the one you picked next to "Color:". Try changing the adapter to use the store's names instead. The color dots in the kettle search results (opens in a new tab) get names too, so check that those still work.
