Write an adapter by hand

For people who code. Redbird turns off the keyboard focus outline, so when you press Tab you can't see where you are. In this guide, you write an adapter that puts it back, and publish it to your toolkit account.

See the issue

  1. Open the store with only issue 20 turned on (opens in a new tab).
  2. Click the search box, then press Tab a few times. The focus moves to the next link or button each time, but nothing on screen shows where it is. If you use a keyboard instead of a mouse, you can't tell which link or button you're on.

The parts of an adapter

An adapter is one file that exports an object with two parts:

  • enable(options, toolkit) changes the page. toolkit has the building blocks. Every change goes through toolkit.session(), which remembers it.
  • disable() ends the session, which puts back exactly what it changed.

An adapter can't import other files, fetch from the network or run text as code. The building blocks do that work for it, like asking AI to rewrite text.

Write the adapter

Save this in a file called focus-ring.js, in the toolkit folder (see Build it in code for the folder and its .env):

JavaScript
// Focus ring: puts back a clear outline around whatever has the keyboard focus.
export const FocusRing = {
  enable(options, toolkit) {
    const s = (this.s = toolkit.session());
    // Twice as thick for someone whose profile asks for more contrast.
    const width = s.profile.get('contrastMode') ? 6 : 3;
    // The store turns the outline off with an !important rule; this one is just as strong.
    s.css(`*:focus-visible { outline: ${width}px solid #0b6e99 !important; outline-offset: 2px !important; }`);
  },
  disable() {
    this.s?.end();
  },
};

s.css() adds a style rule, and s.profile.get() reads the person's toolkit profile.

Publish it

From the toolkit folder, run:

Shell
node .claude/skills/ai4a11y-toolkit/scripts/adapter.mjs publish focus-ring.js --name "Focus ring" --runs-on "https://redbird-workshop.vercel.app/*"

It goes to your account, private to your team, and the extension runs it on the store within a few seconds.

Check that it works

  1. Go back to the store, click the search box and press Tab a few times. A blue outline now moves with the focus.
  2. In the extension's sidebar, under Applied on this page, turn Focus ring off. The outline goes away.
  3. If it didn't run, adapter.mjs status <id> says what went wrong. The most common problem is a missing comma or bracket.

Tip

Change the file and publish it again with the same command. Each publish is a new version, and the page runs it without a reload.
