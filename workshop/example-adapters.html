Example adapters

Four adapters written for Redbird, to read if you want to see how an adapter works or start yours from one. Each one fixes a problem the toolkit didn't cover yet.

Each section has a link to the store with the problem on, the same page with the adapter fixing it, and the code. To change an example, press Copy it into your adapter. The example becomes your adapter, and you can edit it in the Build tab under Describe a fix, in See the code. If you already had an adapter, Go back to the last version brings it back.

real-arrival-dates

Redbird says "5–7 business days" instead of a date, so you have to count the days yourself, skipping weekends. That is hard for people with memory or attention differences and slow with a screen reader. This adapter finds the business-day counts, works out the dates from the store's "today", and writes them in, like "arrives Tue, Nov 3 – Thu, Nov 5". It reads the profile's concreteDates need.

swatch-names

The colors on product pages are plain colored circles with no names, and the keyboard skips them, so a blind shopper can't tell which color they're picking. This adapter finds small, round, empty elements filled with one color, names each one from the closest color in a short list, and turns clickable ones into radio buttons you can move between with the arrow keys. It doesn't change how anything looks.

calm-urgency

Countdown timers, "Only 2 left in stock" and "14 other people have them in their carts" are built to make people hurry, and for someone with anxiety or ADHD they can lead to rushing and buying the wrong thing. This adapter finds these messages by their wording and stops anything blinking. Then it follows the profile's urgency need. With label, it dims each message and adds a short plain note, and with hide, it takes the message off the page and out of what a screen reader reads.

  • The problem (opens in a new tab) · Labeled, for Sam (opens in a new tab) · Hidden, for Mark (opens in a new tab) · Copy it into your adapter (opens in a new tab) · The code (opens in a new tab)

reading-level

Product descriptions are long sentences full of marketing words. This adapter scores each paragraph with the Flesch-Kincaid grade formula, and asks an AI model to rewrite the ones well above the profile's readingLevel, with a button to show the original. It's the only example that uses AI, through options.rewrite(text, instructions), and your own adapters can use it the same way.
