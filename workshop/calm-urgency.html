Hide pressure messages

Redbird uses countdown timers, "Only 2 left in stock" and "14 other people have them in their carts" to rush people. In this guide, you run the calm-urgency adapter with two different profiles, and then teach it one more kind of message.

See the issue

  1. Open the Pebble 2-pack's product page (opens in a new tab) with only issue 24 turned on.
  2. Look under the price. "Deal ends in 04:59:59" counts down, and it starts over every time you reload the page.
  3. Look at the buy box on the right. It says "Only 2 left in stock - order soon." no matter how many are actually left.

Try two profiles

The adapter reads urgency from the profile. Sam's is "label". Mark has ADHD and anxiety, and Mark's is "hide".

  1. Open the product page as Sam (opens in a new tab). The messages are grayed out, with a short note under each one, for example "Sale timer. Timers like this often start over, so there is no need to rush."
  2. Open the product page as Mark (opens in a new tab). The messages are gone, for screen readers too.

Note

The adapter also works in the cart, where Redbird says "14 other people have them in their carts".

Look at the code

The adapter finds the messages by their wording. Each kind of message has a pattern and the note Sam sees. For each pattern, the adapter finds the smallest part of the page that matches, then labels it or hides it. It also stops anything that blinks.

JavaScript
const KINDS = [
  { kind: 'timer', test: /\b(ends in|deal ends|offer ends)\b[^\n]*\d{1,2}:\d{2}/i,
    note: 'Sale timer. Timers like this often start over, so there is no need to rush.' },
  { kind: 'stock', test: /\bonly \d+ left\b/i,
    note: 'Low-stock message. Stores use these to hurry you along.' },
  { kind: 'crowd', test: /\b(\d+ (other )?people|high demand)\b/i,
    note: 'Pressure message. You can take your time.' },
];

To read the whole file, see calm-urgency.js (opens in a new tab).

Add a pattern

Under the stars, the page says "2K+ bought in past month". For some people that's another pressure message, so add a pattern for it.

  1. Open the product page as Mark, with a copy of the adapter in the code box (opens in a new tab).
  2. In the code box, add this right after const KINDS = [:
    JavaScript
      { kind: 'popular', test: /bought in past month/i,
    note: 'Sales count. It shows the product is popular, not that it suits you.' },
  3. Click Save and run. "2K+ bought in past month" is gone too.
  4. To see your note, open the product page as Sam with your copy (opens in a new tab).

Go further (optional)

  • Check the home page as Mark (opens in a new tab). Every deal there has a countdown.
  • Mark's profile also has reduceMotion. Try making the adapter stop the scrolling deals bar at the top of the page (issue 35) when it's set.
