Rewrite hard text

Redbird's product descriptions are long sentences full of marketing words. In this guide, you run the reading-level adapter, which rewrites hard paragraphs at the level the reader asks for with a button to show the original, and then change what it asks the AI model to do.

See the issue

  1. Open the Redbird Basics charger's description (opens in a new tab) with only issue 27 turned on.
  2. Read the description. It starts with "Leveraging next-gen GaN III semiconductor architecture with intelligent PD 3.0/PPS protocol negotiation" and goes on for 33 words in one sentence, without saying what the charger does. This is hard to read for people with dyslexia, and for people reading in a second language.

Turn on the adapter

The adapter scores each paragraph with the Flesch-Kincaid formula, which gives a US school grade from how long the sentences and words are. It rewrites any paragraph of 25 words or more that scores more than two grades above the level the reader chose.

  1. Open the description as Dario (opens in a new tab). Dario has dyslexia and prefers text at about a 6th grade level ("readingLevel": 6).
  2. Wait a few seconds. The description is now a few short, plain sentences, for example "A small 20-watt charger with one USB-C port. It charges most phones to half full in about 30 minutes."
  3. To see the store's text again, click Show original.

Note

The adapter asks Gemini through the workshop site's own server, so you don't need an API key. If the AI isn't available, the adapter uses a plain version that the store keeps for each description.

Change the note

Under each rewrite, the adapter adds a note like "Rewritten at grade 4 (was about grade 27)". A school grade number isn't much use to most readers.

  1. Open the description as Dario, with a copy of the adapter in the code box (opens in a new tab).
  2. In the code box, find the line that starts with note.textContent = and replace it with:
    JavaScript
        note.textContent = 'This is a shorter, simpler version of the store\'s text. ';
  3. Click Save and run. The note now says "This is a shorter, simpler version of the store's text."

Change the instructions (optional)

  1. Open the page with the long return policy (issue 28) turned on too (opens in a new tab). Your copy of the adapter is still in the code box.
  2. In the code box, find const instructions = and add a sentence to it, for example "Explain any technical word in brackets the first time it appears."
  3. Click Save and run, then wait a few seconds. Under "Return policy", the one long legal sentence is now a few short ones, rewritten your way.
