Describe a fix

When no adapter does what a person needs, describe the fix in plain words, and AI writes a new adapter for it. You'll make one for Sam that lets a screen reader read the star ratings. This takes about 20 minutes.

The problem

On Redbird, each product's rating is a picture of stars. A screen reader skips the picture and only reads the number of ratings, like "(1,203)", so Sam can't tell a 3-star charger from a 5-star one. No adapter in the toolkit fixes this yet.

Write the adapter

  1. Open the search results for "charger" (opens in a new tab).
  2. In the Workshop panel, open the Build tab and select Describe a fix.
  3. Press Point at it on the page, then click the stars under any product. This tells the AI which part of the page you mean. With the keyboard, Tab to the part and press Enter.
  4. In What should change on the page?, type: "Read the star ratings out as numbers, like 4.6 out of 5 stars, 1,203 ratings."
  5. Press Write the adapter. It takes about half a minute, and then the page reloads with your adapter on.

Check that it worked

  1. Under Your adapter, press See them. The Changes tab lists each change, with the name a screen reader reads before and after.
  2. Press a change to outline it on the page. The stars look the same as before, since this change is only for the screen reader.
  3. If you can, turn on VoiceOver with Command-F5 and move to the stars.

Change it

AI usually gets close but not exactly right the first time. For example, it might read the rating but leave out the number of ratings. Write what's wrong under Change something and press Ask for the change. The AI changes the code, and the page reloads.

  • If your adapter breaks, its card says what went wrong. Press Ask the AI to fix it.
  • To undo the last change, press Go back to the last version.
  • To read or edit the code yourself, open See the code. It's JavaScript with an enable() that makes the change and a disable() that puts the page back.

Use it in a skill

Once you have an adapter, the Engineer can pick it too. In Make a skill, describe a need it helps with. Your adapter can then show up in the recipe, named mine, next to the toolkit's own adapters.

Note

You have one adapter at a time in this browser. Pressing Write a new adapter replaces it, and pressing Go back to the last version brings the old one back.
